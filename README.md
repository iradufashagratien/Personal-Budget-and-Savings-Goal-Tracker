# Personal Budget & Savings Goal Tracker

## Project Description

The Personal Budget & Savings Goal Tracker is a Python command-line application that helps users manage their personal finances.

The program allows users to record income and expenses, manage savings goals, and view financial summaries. The application uses a menu-driven interface so that users can select different features easily.

The project is developed using Python and is divided into different modules to make the program easier to understand, test, and maintain.

## How to Run the Program

1. Make sure Python is installed on your computer.
2. Download or clone the project from the GitHub repository.
3. Open the project folder in a terminal or command prompt.
4. Run the main program:


python main.py

5. Use the numbered menu to select the feature you want to use.

## Features

### Transaction Management

* Add income and expenses
* View transactions
* Update transactions
* Delete transactions
* Search or filter transactions
* Validate transaction information

### Savings Goals

* Create savings goals
* View savings goals
* Update savings goals
* Delete savings goals
* Add money to a savings goal
* Track savings progress
* Show whether a goal is completed or incomplete

### Analysis and Reports

* Calculate total income
* Calculate total expenses
* Calculate current balance
* Analyse spending by category
* Identify the highest spending category
* Provide financial summaries

### Data Storage

* Save user data using JSON/CSV
* Load previously saved data
* Handle missing or unreadable data files without crashing
